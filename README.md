# GARIK MOY SERVIS ERP - Frontend

Frontend ERP-системы на Next.js 16, React 19 и TypeScript.

## Запуск

```bash
cp .env.example .env.local
pnpm install
pnpm dev
```

По умолчанию интерфейс ожидает API по адресу `http://127.0.0.1:48081`.

## Проверка

```bash
pnpm typecheck
pnpm lint
pnpm build
```

GitHub: `Code` -> `Download ZIP`.
